# ACCT 213 Exam 1 Flashcards

Static flip-card practice deck for ACCT 213 (Stanford GSB, Autumn 2026). Styled after the Nightwalkers squad site.

Single file, no build step. `index.html` is the whole site.

## Deploy

Import this repo at vercel.com/new and accept the defaults (framework: Other). Every push to `main` redeploys.
